# homensai-L-dle-Bestellbuch
Mobile App zur Bestellverwaltung im Hofladen Lädle: Vorbestellungen nach Abholtermin erfassen, Kunden und Artikel anzeigen, benötigte Mengen und Beträge berechnen. Tatsächlich verkaufte Mengen und Preise separat dokumentieren. Übersicht und Sortierung nach Kunden, Artikeln und Terminen sowie Vergleich von Vorbestellungen und tatsächlichen Verkäufen
